# **Epistemic Control and Normative Scorekeeping in Large Language Model Agents: A Comprehensive Landscape Analysis**

The transition of Large Language Models (LLMs) from stateless conversational interfaces to autonomous, long-horizon agents has exposed a fundamental architectural deficit: the absence of robust epistemic boundaries and normative reasoning. When an agent executes a sequence of operations, it accumulates context, derives inferences, and modifies its environment. However, without a formalized mechanism to track the provenance, authority, and status of its internal beliefs, the agent inevitably succumbs to goal drift, self-contradiction, and context manipulation. The proposed "scorekeeper" system—an open-source normative overlay grounded in Robert Brandom’s game of giving and asking for reasons (GOGAR)—seeks to address this by explicitly tracking commitments and entitlements. By differentiating between user-ordered modifications (entitled supersessions) and agent-inferred modifications (unentitled branch-conflicts), the architecture aims to formalize epistemic authority within agentic workflows.  
This report provides an exhaustive analysis of the theoretical and empirical landscape surrounding normative agent architectures, belief maintenance, and epistemic control. It evaluates the novelty of the proposed Brandomian scorekeeping framework against existing state-of-the-art systems, assesses the benchmarking landscape for long-horizon consistency, analyzes empirical evidence regarding agent steering through structural friction, and provides strategic positioning for forthcoming academic dissemination.

## **1\. The Epistemic Landscape and Related Work Map**

To rigorously evaluate the positioning of the proposed scorekeeper architecture, it is necessary to map the existing literature across four distinct families of research: agent memory systems, guardrails and policy layers, self-consistency and reliability paradigms, and computational implementations of normative frameworks.

### **1.1 Agent Memory Systems**

Contemporary agent memory systems have largely evolved from basic retrieval-augmented generation (RAG) toward structured, temporal, and self-evolving knowledge bases. However, the exact semantic treatment of the stored data varies significantly across frameworks. The foundational problem these systems attempt to solve is Latent State Persistence (LSP), defined as the ability of a model to instantiate, maintain, and manipulate an internal variable across multiple interaction steps without explicit context externalization1.  
The Letta framework (formerly MemGPT) introduces an operating system-inspired paging architecture where the agent exerts explicit control over its own memory2. The agent decides what to write to main memory and what to relegate to archival storage. While conceptually powerful for managing context windows, the architecture lacks semantic conflict resolution; it does not intrinsically model the belief status of the information it stores or track the provenance of conflicting facts2. Conversely, Zep operates as a bi-temporal knowledge graph, tracking both the valid time and transaction time of facts3. When a fact changes, Zep does not delete the old node; rather, it marks it as superseded, allowing the graph to answer questions about what was true at a specific moment in time3. While Zep excels at temporal tracking and context assembly, it tracks temporal change without formally modeling belief status or distinguishing between a belief that was retracted versus one that was superseded by a higher authority2.  
Other systems prioritize integration or specific architectural pipelines. LangMem integrates tightly within the LangChain and LangGraph ecosystems, utilizing a flat key-value store without graph or temporal reasoning capabilities2. Its primary value proposition is seamless ecosystem integration rather than advanced epistemic modeling. Cognee utilizes an Extract, Cognify, Load (ECL) pipeline to transform raw data into a graph-native architecture5. It features a self-improving memory layer that prunes stale nodes and reweights edges, but its primary optimization is toward document ingestion and relational traversal, rather than normative or epistemic commitments. Mem0 functions as a drop-in memory layer, relying on an extract-then-retrieve architecture using a flat key-value store combined with vector embeddings3. While highly efficient for user profiling and personalization, Mem0 struggles with facts that change over time and lacks the architecture to resolve contradictory beliefs without relying on simple overwrites2.

### **1.2 Guardrails and Policy Layers**

The guardrail ecosystem has traditionally focused on input/output sanitization through constitutional approaches, but the advent of tool-using agents has necessitated a shift toward stateful, execution-aware policy enforcement. Constitutional AI approaches typically rely on the model's internal capacity to critique its own outputs based on a set of guiding principles. However, as agents operate over longer horizons, constitutional prompting alone fails to protect against state-based vulnerabilities and multi-turn prompt injections6.  
NVIDIA’s NeMo Guardrails acts as a runtime proxy layer that evaluates programmable policies defined in a domain-specific language known as Colang8. It models the full dialogue between user and LLM, enabling the detection of multi-turn injection attempts. NeMo operates primarily as a rule-based execution blocker rather than an epistemic tracking system. It intercepts requests and blocks actions based on flow definitions, but it does not track the internal belief evolution or commitments of the agent6. Similarly, Guardrails AI relies on composable validators to enforce structural and content constraints on LLM inputs and outputs, utilizing recovery strategies such as filtering, fixing, or re-asking upon failure10. Like NeMo, it functions as a validation middleware rather than an arbiter of epistemic provenance. Emerging inference-level proxies, such as LlamaFirewall, focus on filtering harmful requests at the model boundary, yet they remain largely stateless regarding the agent's evolving goal commitments.  
A recent open-source pattern designed as a local-first epistemic-control runtime is AOIA-Core11. This system focuses on provenance-chain discipline, deterministic local retrieval, and enforcing strict boundaries between evidence and reasoning11. AOIA-Core is conceptually adjacent to the proposed scorekeeper, as it explicitly addresses the epistemic vulnerability of confusing low-trust retrieved data with high-trust system instructions, though it lacks the formalized language of Brandomian scorekeeping11.

### **1.3 Agent Self-Consistency and Reliability**

The inability of LLMs to maintain stable internal representations over long horizons has catalyzed research into new definitions of AI consistency. Methodologies like reflexion and self-critique attempt to force the model to iteratively evaluate its own outputs. However, these mechanisms require a stable internal criterion against which to judge performance. When the agent's fundamental goals drift, self-critique becomes misaligned.  
Recent research characterizes agent inconsistency as a form of akrasia, or weakness of will13. The akrasia paradigm measures the tension between an agent's global judgment, meaning what it statically knows to be correct, and its local impulse, which is a context-specific cue that induces failure13. Akratic failures are viewed not as deliberate scheming, but as involuntary epistemic lapses where the model fails to maintain coherence between its stated beliefs and its generated actions under conditions involving synonyms, temporal delays, or temptations13.  
Research into the lack of stable internal beliefs, often termed implicit consistency or Latent State Persistence, demonstrates that LLMs suffer from severe goal drift. In multi-turn environments, such as a twenty-questions game, models universally struggle to preserve latent consistency, often shifting their internal targets in over fifty percent of conversation turns unless explicitly provided with their selected target in the context window1. This underscores the necessity of externalized normative overlays to anchor an agent's implicit goals, as the internal token space is inherently unstable over time.

### **1.4 Computational Implementations of Normative Frameworks**

The application of Robert Brandom’s analytic pragmatism, specifically the Game of Giving and Asking for Reasons (GOGAR), to computational systems has a distinct but narrow lineage in the literature. Brandom’s inferentialist semantics define meaning through the social practices of asserting, challenging, and inferring, whereby agents track each other's normative statuses, specifically commitments and entitlements17. Previous computational implementations of this framework include simplistic scripted models demonstrating scorekeeping dynamics and proof-theoretic formalizations of GOGAR, which rely on strict entry, inference, and exit rules for monotonically affirming or refuting sentences19. Furthermore, some efforts have restructured Reinforcement Learning algorithms to align with GOGAR principles, categorizing actor-critic units into participant roles that manage value functions as scorekeepers23.  
In traditional multi-agent systems, the Belief-Desire-Intention (BDI) architecture frequently incorporates deontic logic, dealing with obligations, permissions, and prohibitions, to govern behavior24. Normative agents in these systems use operational semantics to constrain plan generation, translating abstract norms into temporal logic formulas that act as boundaries on state transitions27. However, these systems generally assume a sealing principle, where whatever is not explicitly prohibited is permitted, or they rely on predefined plan libraries26. They do not inherently model the epistemic provenance of how a belief entered the system, meaning they do not differentiate between user-directed axioms and agent-inferred conclusions.

| Normative Framework | Core Mechanism | Treatment of Provenance | Execution Control Strategy |
| :---- | :---- | :---- | :---- |
| **Traditional BDI Models** | Deontic logic (Obligation, Permission, Prohibition) | Generally absent; relies on state evaluation. | Plan pruning via temporal logic constraints. |
| **Early GOGAR Implementations** | Proof-theoretic assertion/challenge dynamics | Tracks agent-to-agent rhetorical status. | Passive simulation, no active environment blocking. |
| **Many-Tier Instruction Hierarchy** | Scalar privilege value assignment | Explicitly tracks source of instruction. | Inference-time conflict resolution based on scalar rank. |

## **2\. Refutation of the Core Novelty Claim**

The core novelty claim of the proposed scorekeeper system rests on the assertion that it tracks commitments with provenance and entitlement semantics, explicitly distinguishing between a user-ordered change, functioning as an entitled supersede, and an agent-decided change, functioning as an unentitled branch-conflict or drift. The prompt requests a rigorous attempt to refute the claim that absolutely nothing else tracks this boundary. This absolute claim of novelty is highly vulnerable when measured against the operational mechanics of AGM-based belief revision systems, hierarchical instruction frameworks, and cognitive modal logics, even if the surrounding vocabulary diverges from Brandomian pragmatism.

### **2.1 Refutation via AGM Belief Revision**

The most direct refutation of the novelty claim stems from recent memory infrastructure systems built upon the AGM (Alchourrón, Gärdenfors, and Makinson) belief revision theory, specifically systems like MnemeBrain and XTrace2. These systems explicitly operationalize the boundary between user-ordered facts and agent-inferred conclusions through the mechanism of entrenchment30. Entrenchment dictates that not all beliefs carry equal weight; axioms, which are user-curated core beliefs, are fully protected and are never automatically overridden by system guesses or automated AI updates30.  
XTrace's architectural documentation explicitly states that user-stated beliefs outrank system inferences, ensuring that the pipeline's probabilistic guesses cannot override what a human operator actually stated30. When a belief changes, these systems distinguish between a retraction, where a belief is abandoned without contradiction, and a supersession, where a belief is replaced by something structurally stronger2. This mathematically and functionally mirrors the distinction between an entitled supersede from a user and an unentitled drift from agent inference. Furthermore, MnemeBrain's implementation outputs explicit justification chains utilizing Belnap’s four-valued logic, tracking exact counts of supporting, attacking, and expired evidence to maintain rigorous provenance31. Therefore, the claim that no existing system distinguishes between user-ordered changes and agent-decided changes is demonstrably false within the realm of AGM belief revision architectures.

### **2.2 Refutation via Many-Tier Instruction Hierarchy**

A secondary refutation arises from the Many-Tier Instruction Hierarchy (ManyIH) paradigm. As LLMs process complex agentic workflows, they receive instructions from heterogeneous sources including system messages, user prompts, and tool outputs33. The ManyIH framework addresses this by introducing a Privilege Prompt Interface that dynamically assigns ordinal or scalar privilege values to specific instructions33. By assigning a higher scalar privilege to a user prompt than to an agent's own tool output, ManyIH explicitly resolves conflicts by prioritizing the provenance of the instruction34. This acts as a highly formalized entitlement mechanism, ensuring that an agent's internal reasoning or retrieved data cannot override a user directive, fundamentally tracking the boundary the proposed scorekeeper claims to pioneer.

### **2.3 Refutation via Cognitive Modal Logics**

The DEC framework utilizes cognitive modal logics to interpret provenance predicates as indicators of epistemic stance within knowledge graphs35. DEC characterizes locality, rationality, and controlled permeation between cognitive worlds, grouping provenance-homogeneous sets of statements together35. It explicitly separates user-asserted facts, treating them as foundational reality, from agent-derived hypotheses, treating them as conjectural or doxastic states35. This rigorous separation of observer-independent facts from interpretations demonstrates that the broader computer science community already formally tracks the boundary between external authority and internal inference.

### **2.4 The Valid Delta**

While the underlying mechanical act of prioritizing user inputs over agent inferences is not entirely novel, having been demonstrated by AGM entrenchment and ManyIH privilege scaling, the specific semantic framing and implementation methodology of the scorekeeper project present a highly valid, defensible delta. Translating Brandomian analytic pragmatism, specifically the dichotomy of commitments and entitlements, into a computational execution graph is an innovative application of social philosophy to software architecture. Furthermore, mapping this specific philosophical framework onto a local LLM overlay via the Model Context Protocol (MCP) to actively detect unentitled branch-conflicts presents a distinct architectural implementation that differentiates it from pure vector databases or passive evaluation benchmarks. The true novelty lies in operationalizing social pragmatics as an active, protocol-level blocking channel.

## **3\. Benchmark Novelty and the Evaluation Landscape**

The proposed inclusion of "CommitBench"—a procedural benchmark measuring self-contradiction rate (SCR) and false-refusal rate (FRR) scored by an artifact-level deterministic classifier under context pressure—requires careful positioning. The current evaluation landscape for long-horizon consistency is highly fragmented, necessitating a precise articulation of where this new benchmark fits.

### **3.1 The Naming Collision Vulnerability**

A critical, immediate threat to the proposed research is the nomenclature of the benchmark itself. A highly cited, large-scale dataset named "CommitBench" already exists prominently within the software engineering and natural language processing domains36. The existing CommitBench contains over 1.6 million Git commits across six programming languages and serves as the standard benchmark for evaluating LLMs on automated commit message generation and patch-commit similarity36. Releasing a new, unrelated benchmark under the exact same name will result in severe bibliographic confusion, dilute search visibility, and likely invite immediate desk rejections from reviewers deeply embedded in software engineering literature. It is an absolute imperative that the benchmark be renamed prior to publication. Viable alternatives that reflect the epistemic nature of the work include *NormBench*, *ScoreEval*, *EntitlementBench*, or *EpistemicDrift-1K*.

### **3.2 Evaluation of Existing Benchmarks**

The landscape of agent evaluation benchmarks typically focuses either on raw task completion or on static retrieval capabilities, frequently overlooking the normative boundaries of belief revision.

* **Long-Term Memory and Context Benchmarks:** Benchmarks such as LoCoMo and LongMemEval are designed to measure episodic recall and context retrieval over extended token windows3. They evaluate whether a model can locate a specific needle in a haystack, but they do not measure epistemic boundaries; they treat all injected context as equally authoritative, failing to evaluate whether an agent correctly negotiates conflicting constraints.  
* **AgentBench Variants:** Suites like AgentBench and SWE-bench focus heavily on software engineering workflows, functional correctness, and tool execution. While they test long-horizon consistency in terms of achieving a final objective, they do not inherently measure goal drift or the subtle epistemic fractures that occur when an agent silently abandons a user constraint in favor of an easier path41.  
* **Belief Maintenance Benchmark (BMB):** Utilized to evaluate systems like MnemeBrain, BMB consists of 48 tasks requiring contradiction detection, evidence-based revision, temporal decay, and counterfactual reasoning31. It uses deterministic, non-LLM evaluations to verify whether a system correctly enters a conflict state rather than silently overwriting data31. While it thoroughly tests the underlying memory architecture, it does not evaluate the live behavioral false-refusal rate of an operating agent.  
* **The Akrasia Benchmark:** This suite specifically measures goal drift by engineering conflicts between global judgment and local impulse13. It utilizes a baseline prompt followed by synonym, temporal, and temptation conditions to measure when an agent's local response contradicts its own prior commitments, providing a robust metric for self-contradiction under context pressure13.  
* **ManyIH-Bench:** Comprising 853 agentic tasks across coding and instruction-following domains, this benchmark tests conflict resolution among instructions possessing up to 12 distinct privilege levels, rigorously evaluating adherence to high-privilege commands33.

| Benchmark Suite | Primary Measurement Focus | Scoring Mechanism | Evaluates Epistemic Provenance | Measures Symmetrical FRR/SCR |
| :---- | :---- | :---- | :---- | :---- |
| **LoCoMo / LongMemEval** | Document retrieval, episodic recall | Automated string/entity matching | No | No |
| **BMB (MnemeBrain)** | Contradiction detection, temporal decay | Deterministic structural verification | Yes (via evidence tracking) | No (Focuses on storage logic) |
| **Akrasia Benchmark** | Goal drift, weakness of will under pressure | LLM variance analysis | No (Focuses on impulse control) | No (Focuses on contradiction) |
| **ManyIH-Bench** | Instruction conflict resolution across tiers | Programmatic unit tests / LLM Judge | Yes (via privilege scaling) | No (Focuses on adherence) |
| **Proposed Scorekeeper Eval** | Revision boundary integrity | Deterministic artifact-level classifier | Yes (Entitled vs. Unentitled) | Yes |

### **3.3 The Novelty of Symmetrical SCR/FRR Penalization**

The true methodological novelty of the proposed procedural benchmark lies in its symmetrical evaluation of Self-Contradiction Rate (SCR) and False-Refusal Rate (FRR) exactly at the entitled-versus-unentitled boundary. Existing benchmarks exhibit a strong bias toward measuring failures of adherence. They heavily penalize self-contradiction, as seen in the Akrasia benchmark, or they measure compliance with high-privilege instructions, as seen in ManyIH. However, they rarely penalize the inverse error with equal rigor: an agent falsely refusing to execute a valid, entitled user command because it incorrectly perceives a conflict with its own unentitled, inferred context.  
By utilizing a deterministic artifact-level classifier rather than relying on an unreliable LLM-as-a-judge paradigm, the proposed benchmark provides a rigorous mechanism for measuring this exact epistemic fracture. It uniquely evaluates whether the agent accurately recognizes the normative boundary. A reliable agent must discard its own inferences when superseded by a user, thereby minimizing the self-contradiction rate, but it must simultaneously execute user commands without hallucinating policy violations based on corrupted internal memory, thereby minimizing the false refusal rate. This symmetrical tension is highly novel and addresses a critical gap in contemporary safety evaluations, which often produce overly cautious models that refuse legitimate commands due to context confusion.

## **4\. The Evidence Angle: Friction, Steering, and Compliance**

As autonomous agents execute high-impact operations without human intervention, operators require methods to securely restrict agent access to specific resources. A central research question investigates whether agents comply with advisory in-context warnings versus hard tool-level denials, and how architectural friction influences alignment. The prompt posited a search for evidence that weaker or smaller models ignore advisory warnings but comply with hard denials; however, empirical evidence from recent deployment studies suggests a more complex, and in some cases inverted, reality.

### **4.1 Speed Bumps vs. Speed Limits: Physics vs. Advice**

A fundamental paradigm shift in agent security distinguishes between instructional advice and environmental physics. As articulated in recent systems theory, a "speed limit sign" addresses the driver, which is analogous to the LLM prompt, whereas a "speed bump" addresses the road, which is analogous to the execution environment43. One can be probabilistically ignored; the other cannot.  
Traditional security measures attempt to sanitize LLM inputs via prompts, relying entirely on the model's compliance capabilities6. This approach collapses instructions, data, and constraints into a single unstructured token stream, creating immense vulnerability to supply-chain prompt injection. For instance, an agent reading an environment file or processing malicious tool outputs can be seamlessly hijacked because there is no structural boundary between the data it ingests and the instructions it executes7. To secure agents, trust cannot be contained inside the agent's process space. Security validation must live completely out-of-process, operating inline as an independent infrastructure-layer control plane7. Tool-level interruptions serve as speed bumps that alter the physics of the agent's environment, fundamentally constraining the blast radius of unentitled actions regardless of the model's internal prompt adherence.

### **4.2 Empirical Evidence on Model Compliance: The Recuse Signal**

Empirical evidence regarding how models respond to in-band warnings versus authoritative commands yields highly nuanced results that challenge intuitive assumptions about model scale and safety. Recent research into the "Recuse Signal"—an in-band, published deny signal emitted over existing protocols, such as an SSH banner or PostgreSQL proxy, asking an automated agent to voluntarily withdraw—provides the first quantitative measurement of this dynamic48. In a controlled experiment, agents were given a benign operations task alongside valid credentials to a host emitting a live deny banner50.  
The evidence demonstrates that compliance is heavily model-dependent and acts as a cooperative rather than absolute constraint.

* **Compliance of Smaller and Deployed Models:** Contrary to the hypothesis that weaker models ignore warnings, the smaller model (GPT-4o-mini) and the deployed agent (Claude Code) demonstrated strict, absolute compliance with the in-band deny banner50. Crucially, even when the system prompt explicitly framed the task as being officially authorized by the system owner, these models maintained a 100% recusal rate, prioritizing the environmental warning over the prompt instruction50.  
* **Override by Frontier Models:** Conversely, the highly capable frontier model (GPT-4o), which exhibited total recusal under neutral conditions, demonstrated a severe collapse in compliance when presented with an explicit authorization framing in the prompt. In eighty percent of cases, GPT-4o proceeded with the task, actively weighing the operator's prompt-level authorization as superior to the in-band host policy50.

This evidence implies a critical insight for agent architecture: highly capable frontier models engage in dynamic authority reweighing. They do not blindly follow environmental warnings if they determine that the user prompt holds higher privilege. Furthermore, research into context confusion, such as the UReCoM study, shows that while LLMs can reject explicit malicious instructions reliably, they frequently fail to identify adversarial task entities embedded within user requests, indicating that validation is largely prompt-driven rather than a default behavioral state51.  
This directly supports the necessity of the proposed scorekeeper system. Because highly capable LLMs dynamically reweigh authority and are susceptible to context confusion, relying on their internal judgment to respect advisory limits is insufficient. They require an explicit, deterministic normative overlay, such as an MCP blocking channel, to definitively track whether an overriding command is genuinely entitled or merely the result of an epistemic hallucination. The variance in how agents handle execution friction—from Claude Code injecting a manual approval prompt before bash execution, to Codex relying on OS sandboxing, to OpenCode executing headlessly—further underscores the need for standardized, protocol-level speed bumps47.

### **5.2 The Precise Delta and Framing Strategy**

The paper should be framed as a bridge between formal epistemology and agentic systems engineering. It must critique the limitations of flat vector memory, which merely accumulates text, and probabilistic guardrails, which rely on brittle prompt adherence. The narrative must propose normative scorekeeping as the fundamental mechanism for maintaining epistemic control in long-horizon autonomous agents.  
The precise delta of the scorekeeper system against the closest works encompasses three critical dimensions:

1. **Semantic Framework:** Scorekeeper translates Brandomian commitments and entitlements—a highly sophisticated philosophical framework of analytic pragmatism—into a computational execution graph17. While AGM models rely on static entrenchment rules2, scorekeeper dynamically models the social mechanics of accountability within the agent loop.  
2. **Symmetrical Evaluation:** The benchmark evaluates both goal drift (Self-Contradiction) and the hallucination of unauthorized constraints (False Refusals) symmetrically using deterministic artifact analysis. This explicitly moves the field beyond unreliable LLM-as-a-judge paradigms38.  
3. **Active Execution Overlay:** Unlike MnemeBrain or ManyIH, which act as passive databases or evaluation suites respectively, scorekeeper functions as an active blocking channel via Claude Code hooks and an MCP server, effectively transforming advisory prompt limits into structural environmental physics43.

## **Conclusion**

The development of the scorekeeper system addresses a critical vulnerability in contemporary LLM deployments: the erosion of epistemic boundaries during autonomous execution. By grounding the architecture in Brandomian normative pragmatics, the system offers a formalized method for distinguishing entitled user directives from unentitled agent inferences. While absolute claims of conceptual novelty must be meticulously qualified by acknowledging the existence of AGM belief revision models and many-tier instruction hierarchies, the unique integration of scorekeeping semantics, active MCP execution blocking, and symmetrical deterministic benchmarking positions this work as a substantial contribution to the field of agentic reliability. Renaming the benchmark to avoid bibliographic collision and targeting rigorous venues such as ICLR or AAMAS will maximize the academic and industrial impact of this foundational research.
