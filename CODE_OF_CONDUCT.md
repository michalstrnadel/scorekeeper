# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

In short: be respectful, assume good faith, critique ideas rather than people, and keep it welcoming for newcomers — the project is early and questions are expected.

Report unacceptable behavior to the maintainer via a private message on GitHub (@michalstrnadel). Reports are handled confidentially.
